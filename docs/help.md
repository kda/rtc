# Help

Every single keystroke is documented here to provide a complete reference.

Of course, every section may be quickly referenced by typing `?` followed by the key in question.

# Help For Each Specific Key

Everything below here is used to populate the interactive help system.

## backspace
Delete  (del)

Delete the last character entered into the accumulator.

## enter
Calculate   (enter)

Conduct the calculation using the pending operation and accumulator.

## escape
Clear    (esc)

Clear the current context.

Clears the current value (sets to zero).

It can also be used to stop:
-   picking a number of significant digits
-   picking the register to store to 
-   picking the register to recall from
-   viewing the current help text

## pound
Constants   (#)

Insert a well known constant.

## percent
Modulo      (%)

Determine remainder in division, sometimes called modulo.

## asterisk
Multiply    (*)

Perform multiplication.

## plus
Add         (+)

Perform addition.

## minus
Subtract    (-)

Perform subtraction.

## dot
Decimal point   (.)

Enter the decimal point of a decimal or scientific number.

## slash
Divide      (/)

Perform division.

## 0
Zero    (0)

Enter the number 0.

## 1
One     (1)

Enter the number 1.

## 2
Two     (2)

Enter the number 2.

## 3
Three   (3)

Enter the number 3.

## 4
Four    (4)

Enter the number 4.

## 5
Five    (5)

Enter the number 5.

## 6
Six     (6)

Enter the number 6.

## 7
Seven   (7)

Enter the number 7.

## 8
Eight   (8)

Enter the number 8.

## 9
Nine    (9)

Enter the number 9.

## equals
Equals  (=)

Conduct the calculation using the pending operation and accumulator.

## bing
Help    (?)

Follow this key by any other key to learn how that key functions.

## A
Decimal     (A)

Work in decimal (point) mode.

## B
Binary      (H)

Use base-2 (binary).

## C
Change sign (C)

Invert the sign of the value in the accumulator.

## D
Decimal     (D)

Use base-10 (decimal).

## E
Exponent    (E)

Beginning enter the exponent part of the scientific number.  (Requires being in the scientific numeric mode (S).)

## F
Significant Digits  (F)

Set the number of significant digits (0-9).

## H
Hexadecimal (H)

Use base-16 (hexadecimal).

## I
Integer     (I)

Work in integer (whole numbers) mode.

## M
Memory  (M)

Show (or hide) memory registers.

## O
Octal       (O)

Use base-8 (octal).

## S
Scientific  (S)

Work in scientific mode.

## V
Version     (V)

Show Version information about RTC.

## a
a (base-16) (a)

Enter the hexadecimal number a.

## b
b (base-16) (b)

Enter the hexadecimal number b.

## c
c (base-16) (c)

Enter the hexadecimal number c.

## d
d (base-16) (d)

Enter the hexadecimal number d.

## e
e (base-16) (e)

Enter the hexadecimal number e.

## f
f (base-16) (f)

Enter the hexadecimal number f.

## q
Quit    (q)

Quit.  Exit the calculator.

## r
Recall  (r)

Retrieve a memory register into the accumulator.

## s
Store   (s)

Store the current value in a memory register.
